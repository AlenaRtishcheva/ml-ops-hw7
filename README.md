# ML-OPS-HW7: Автоматизированный конвейер обучения и деплоя модели Iris

Данный проект представляет собой реализацию полноценного MLOps-цикла: от автоматизации обучения (CI) до развертывания сервиса с использованием стратегии Canary Deployment (CD).

## 📂 Структура проекта

*   **`.github/workflows/`** — конфигурации CI/CD пайплайнов:
    *   `ci.yml` — проверка кода и обеспечение воспроизводимости обучения.
    *   `deploy.yml` — сборка и публикация Docker-образа в реестр пакетов.
*   **`ml_pipeline.py`** — основной скрипт на базе **FastAPI**, выполняющий обучение модели RandomForest и предоставляющий API-интерфейс.
*   **`Dockerfile`** — инструкции по сборке изолированного контейнера для работы модели.
*   **`docker-compose*.yml`** — конфигурации для управления мультиконтейнерной средой:
    *   `docker-compose.yml` — основной файл для запуска Canary-инфраструктуры.
    *   `docker-compose.blue.yml` / `.green.yml` — конфигурации для изолированного запуска версий.
*   **`nginx.conf`** — настройки балансировщика трафика для распределения нагрузки между версиями модели.
*   **`ADR.md`** — запись архитектурного решения (Architecture Decision Record) по выбору стратегии деплоя.
*   **`requirements.txt`** — список зависимостей с зафиксированными версиями библиотек.

## 🚀 Технологический стек

*   **Модель:** [Scikit-learn](https://scikit-learn.org) (RandomForestClassifier)
*   **API:** [FastAPI](https://tiangolo.com) + Uvicorn
*   **Контейнеризация:** [Docker](https://docker.com) & Docker Compose
*   **Балансировщик:** [Nginx](https://nginx.org)
*   **CI/CD:** [GitHub Actions](https://github.com)

## 🛠 Запуск проекта

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   ```

2. **Запустите Canary-стек (Blue, Green и Gateway):**
   ```bash
   docker-compose up -d --build
   ```

3. **Проверьте доступность сервиса:**
   ```bash
   curl http://localhost:9080/health
   ```

## 📊 Стратегия деплоя
В проекте реализована стратегия **Canary Deployment** с разделением трафика 90/10. Это позволяет безопасно тестировать новую версию модели на ограниченном сегменте запросов через балансировщик Nginx.
